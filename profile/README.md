## iwantools

爱玩工具站（iwantools）官方组织：研发并交付商业后台管理基座 **Iwan Admin**。

客户基于 Iwan Admin 开发自己的业务，通过 Git 共同历史持续接收基座的功能更新与缺陷修复：

**基座开发 → 独立业务使用 → 通用修复发布 → 业务接收升级**

## 合作方式

提供付费源码与部署包，帮助客户快速启动业务、验证 MVP，并提供一定的使用指导；客户自行管理源码、业务数据、凭证与部署环境。详见官网。
