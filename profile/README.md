## 我们做什么

不是外包，也不是 SaaS——我们交付一套**可长期演进的工程基座**：

- **一次搭建**：完整 IAM、系统管理、动态菜单、监控与部署件，直接开始业务开发
- **持续升级**：基座缺陷与通用能力由官方持续发行，客户经 Git 三方合并平滑接收，业务与数据完整保留
- **客户自主**：付费源码 + 部署包，源码、数据、凭证与部署环境全归客户

**基座开发 → 独立业务使用 → 通用修复发布 → 业务接收升级**
